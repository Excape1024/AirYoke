# AirYoke 1.5.1 详细使用教程

本教程适用于 Windows 10/11、Android 13+ 和 Microsoft Flight Simulator 2020。AirYoke 由手机端 APK 与电脑端桥接程序两部分组成，两端版本必须一致。

## 一、下载与安装

### 1. 下载发布文件

本轮是本地测试包，未上传 Releases。使用工作区 `dist` 中配套产物：

- `AirYoke-v1.5.1/AirYoke-v1.5.1.apk`：安卓手机端。
- `AirYoke-v1.5.1-Windows-x64.zip`：Windows 桥接程序、ADB 文件和随包说明。

本地安装包与桥接程序应配套更新；覆盖安装手机端可保留原校准和设置。

### 2. 安装手机端

1. 把 APK 发送到手机或直接用手机下载。
2. 点击 APK 安装。
3. Android 若提示不允许安装未知应用，进入提示所指的设置页面，为当前浏览器或文件管理器临时授权。
4. 安装完成后可以关闭这项临时授权。

当前 APK 使用调试签名。以后安装不同签名的版本时，Android 可能要求先卸载旧版本；卸载会清除 AirYoke 的校准和设置。

### 3. 准备电脑端

1. 把 `AirYoke-v1.5.1-Windows-x64.zip` 解压到普通文件夹，例如桌面或文档目录。
2. 保持 `AirYoke.Bridge.exe` 与 `platform-tools` 文件夹在同一解压目录中。
3. Windows 若显示 SmartScreen 提示，请先核对文件来源和发布页校验值，再根据自己的安全策略决定是否运行。

桥接程序为 Windows x64 自包含版本，无需另装 .NET Runtime。

## 二、连接手机和电脑

AirYoke 支持两种连接方式，并自动选择可用通道。建议先使用方式 A；不方便开启网络共享时使用方式 B。

### 方式 A：USB 网络共享

1. 使用支持数据传输的 USB 线连接手机与电脑。
2. 在手机系统设置中打开“USB 网络共享”。不同品牌可能位于“连接与共享”“个人热点”或“USB 设置”中。
3. Windows 出现新的有线网络接口后，运行 `AirYoke.Bridge.exe`。
4. 打开手机 AirYoke。程序会通过 UDP 广播自动发现电脑，不需要填写 IP。

若 Windows 防火墙首次询问是否允许通信，只需允许当前可信的 USB 网络。AirYoke 使用 UDP 端口 `9000`。

### 方式 B：USB 调试与 ADB

1. 在手机“关于手机”页面连续点击版本号，开启开发者选项。
2. 在开发者选项中打开“USB 调试”。
3. 用 USB 线连接电脑；手机弹出 RSA 授权时，确认电脑是自己的设备后点击允许。
4. 运行 `AirYoke.Bridge.exe`。桥接程序会使用旁边的 `platform-tools/adb.exe` 自动建立端口映射。
5. 打开手机 AirYoke，等待状态变为“已连接”。

锁屏、重新插线或重启 ADB 后，端口映射可能失效。桥接程序会在没有活动连接时尝试恢复；若仍未连接，关闭桥接程序、解锁手机并重新运行。

## 三、首次启动与校准

1. 启动 MSFS2020，进入 iniBuilds A320neo V2 或 FlyByWire A32NX 稳定版的驾驶舱。
2. 运行电脑端 `AirYoke.Bridge.exe`。模拟器尚未就绪时，程序会每 5 秒自动重试。
3. 打开手机 AirYoke，点击左上角机模名称或“设置”，选择与驾驶舱一致的机模。选择会保存在手机中。
4. 以平时操纵的姿势握住手机，保持自然水平和稳定。
5. 点击顶部“校准”。
6. 状态栏显示“已连接”后，小幅倾斜手机检查副翼和升降舵方向。

若方向相反，点击“设置”，勾选“副翼反转”或“升降舵反转”，保存后重试。校准和方向设置会保存在手机中。

## 四、界面与操作

### 体感操纵

- “操纵·开”：手机倾斜控制副翼和升降舵。
- “操纵·关”：向模拟器发送中立的副翼和升降舵值，方便放下手机或只使用触控控件。
- 中央姿态仪显示相对校准姿态。

每次改变握持姿势或手机放置角度后，应重新点击“校准”。

### 油门与自动油门

左侧竖杆从下到上为反推、慢车、CL、FLX、TOGA，卡位带吸附和震动反馈。

1. 点击“推力·交还”，切换为“推力·手动”，手机才会持续控制油门。
2. 拖动油门杆设定目标。橙色细线表示发送目标，主滑块始终显示模拟器回传的位置；正推力松手后继续保持目标指令。
3. 反推区松手、触摸取消或应用离开前台时会自动回到慢车。
4. 再次点击顶部推力按钮交还控制。手机会短暂发送 CL 目标，然后停止覆盖油门，让座舱自动油门接管。

交还控制不会替你打开座舱的 A/THR。请按飞机正常流程操作自动油门。

手动接管、拖动、松手和交还期间，主滑块都跟随飞机位置反馈；反馈不会修改正在发送的目标。交还时不会把主滑块直接跳到 CL，而是等待飞机回读。

左侧白色①、蓝色②分别表示两根真实座舱杆位，不取平均值。双杆没有对齐时暂不允许统一接管，先在座舱对齐。尚未收到位置时不显示实际滑块；回读失效或样本过期约 500 毫秒后，最后位置变灰并明确提示过期，同时停止接管。切换机模会清除旧反馈，不会发送 CL。恢复反馈后需要重新点击接管。

双发 N1 分别由所选机模的发动机变量回读，保留一位小数；N1 是低压转子转速百分比，不是推力百分比。自动推力工作时，座舱杆位可以停在 CL 而 N1 变化，手机也应如此。不会用用户目标、通用油门变量或平滑动画代替真实杆位。

两款机模均按慢车 0°、CL 25°、FLX 35°、TOGA 45°映射界面。电脑读取飞机 EFB 的两根轴独立校准，向每根轴发送其卡位中心。使用反推前，需要在 EFB 启用并校准双轴反推；未启用时手机明确提示，负向拖动不发送反推。不会自动修改飞机校准设置。

正常遥测约每秒 10 次。界面的“样本年龄”是桥接采样到发送以及手机收到后的已知年龄，不包含无法直接测量的传输耗时，不能当作完整端到端延迟。零延迟逐帧一致无法保证，游戏内精度与延迟必须实测。

机模不匹配、未识别或局部变量/校准未就绪时，不会退回通用变量伪造正常显示。可运行 `AirYoke.Bridge.exe --enginewatch-v2` 或 `--enginewatch-fbw` 进行十秒只读诊断；该命令不接收手机输入、不发送控制事件。

### 断开自动驾驶

右侧刹车按钮上方新增“断开自动驾驶”。单击后显示“断开请求／等待确认”，后续有效回读确认自动驾驶关闭时显示“自动驾驶／已断开”。按钮只发送关闭指令，重复点击不会打开自动驾驶，也不会改变自动油门或手机操纵开关。

请求最多在 800 毫秒窗口内重发，桥接端首次立即发送、随后最多每秒 10 次。确认关闭、连接失效或应用进入后台后停止请求；超时仍未确认时显示“断开未确认／点击重试”，需要再次点击才会重试。

没有有效连接时按钮禁用并显示“等待连接”。两端必须配套升级 1.5.1，旧协议拒收。回读不能替代机型验证；第三方飞机对标准断开事件的支持需在地面确认。

### 方向舵

中央下方横杆控制方向舵，松手自动回中。

### 减速板与预位

- 右侧“减速板”竖杆连续控制位置，上收、下放。
- “预位”按钮独立控制减速板预位状态。
- 手机会显示模拟器回传的位置。出现“指令未确认”时，请以驾驶舱实际状态为准。

### 刹车与驻车

- 按住“刹车”同时施加左右轮刹车，松手释放。
- “驻车”按钮切换驻车刹车，并等待模拟器状态回传确认。

### 襟翼

最右侧竖杆有 `0 / 1 / 2 / 3 / 全` 五个离散档位。拖动到目标档位后，检查驾驶舱手柄和手机回传是否一致。

## 五、状态信息

- `已连接 · xx Hz`：手机、桥接程序和模拟器遥测均正常。
- `电脑已连 · 等待模拟器`：手机已找到桥接程序，但模拟器未连接或遥测尚未齐全。
- `等待电脑桥接 1.5.1（需两端配套）`：尚未连接电脑桥接程序。
- `指令未确认`：发送目标与模拟器回读尚未一致；不要把手机滑杆位置当作飞机已经执行。
- `AP`、`A/THR`：显示模拟器回传的自动驾驶和自动油门状态。

## 六、常见问题

### 手机一直显示“等待电脑桥接 1.5.1”

1. 确认手机端和桥接端均为 1.5.1。旧版桥接会拒收新协议。
2. 确认 USB 线支持数据传输，尝试更换接口或线缆。
3. 使用方式 A 时，确认 USB 网络共享已打开；使用方式 B 时，确认 USB 调试授权没有被撤销。
4. 确认没有第二个桥接程序占用 TCP/UDP 端口 `9000`。
5. 查看桥接窗口是否报告端口占用或 ADB 错误。

### 电脑已连，但显示“等待模拟器”

1. 确认 MSFS2020 已经进入主界面或飞行。
2. 等待桥接程序自动重试连接。
3. 运行 `AirYoke.Bridge.exe --simtest` 单独检查 SimConnect。
4. 若模拟器安装在非常规位置，可把模拟器自带的 `SimConnect.dll` 放到桥接程序旁边；不要从不可信网站下载 DLL。

### 飞机操纵方向相反

进入手机“设置”，分别切换副翼或升降舵反转，然后重新校准。桥接端还会按 SimConnect 轴定义做方向转换，不要同时在多个位置重复反转。

### 自动油门报警或与手机抢油门

确认顶部显示“推力·交还”。交还后 AirYoke 只短暂发送 CL，随后停止写入油门。座舱 A/THR 仍需按机型正常流程开启。

### 襟翼、减速板或驻车没有动作

当前版本使用标准 SimConnect 事件。先确认完整机型名称，并观察是否出现“指令未确认”。不同的第三方 A320 可能不响应这些标准事件，需要单独适配。

### 如何安全检查手机链路

在桥接程序目录打开命令行，运行：

```powershell
.\AirYoke.Bridge.exe --dry-run
```

此模式只显示手机输入，不连接或操纵模拟器。`--selftest` 只运行内存中的协议与控制逻辑测试。

## 七、退出与断线保护

正常退出桥接程序可按 `Ctrl+C`。手机应用离开前台时会释放反推、刹车和触控状态；桥接端在 500 毫秒没有收到输入时也会释放反推、刹车、副翼、升降舵和方向舵。

断线保护不能代替安全操作。测试新机型或新版本时，请在地面、低风险状态下进行，并准备使用实体控制器接管。
